# 연구용 인공지능 서비스 활용 소명서

## 1. 어떤 연구를 수행하는 데 사용하는가

본 과제는 **사람의 뇌가 시각·청각 등 여러 감각 정보를 통합 처리하는 원리를 규명하고, 불완전한 환경에서도 안정적으로 작동하는 다중감각 인공지능을 개발하는 연구(연구 1-4)**입니다.

연구팀은 뇌 활동 데이터 분석, 신호 결측 보완 알고리즘 개발, 감각 통합 인공지능 모델 검증을 수행하며, 인공지능 서비스(Claude)는 **연구 프로그램 작성 및 알고리즘 검증, 수식과 구현의 일관성 점검, 대규모 실험 데이터 통계 분석**을 보조하는 필수적인 연구 연산 기기로 활용합니다.

## 2. 연구 과정에서 구체적으로 어떻게 사용하는가

| 수행하는 세부 연구 단계 | 인공지능 서비스의 구체적 활용 목적 및 방법 |
|---|---|
| **뇌 정보처리 원리 규명**<br>• 복합 감각 뇌신호 모델링 | 뇌의 빠른 반응과 느린 기억을 수식화한 이론과 실제 프로그램 구현의 일치 여부를 대조하고, 뇌 활동 시계열 분석 및 데이터 시각화 프로그램을 작성·점검합니다. |
| **불완전 측정자료 복원**<br>• 결측 뇌신호 보완 알고리즘 | 측정 과정에서 일부 신호가 누락되거나 손실된 뇌 측정자료를 복원하는 과정에서 알고리즘의 결측 처리 오류를 조기에 발견·수정하고 재발 방지 검증을 수행합니다. |
| **인공지능 모델 통합·검증**<br>• 다중감각 모델 종합 평가 | 수십 가지 실험 조건별 성능 비교 및 통계 검증 코드를 작성하고, 연구 논문과 보고서에 제시되는 실험 수치와 해석의 정확성을 다각도로 교차 검증합니다. |

**연구책임자 직접 활용 및 검증 원칙:** 연구책임자(차지욱 교수)가 연구 가설과 비교 조건을 직접 설정하고, AI가 제안한 프로그램과 분석 해석을 실제 연구 데이터와 실행 결과에 엄격히 대조하여 검증된 내용만 연구 결과물에 채택합니다.

## 3. 왜 여러 구독과 많은 사용량이 필요한가

단발성 질문-답변이 아니라 여러 연구원이 각자 세부 실험을 동시에 진행하면서 **「분석 설계 → 수천 줄의 연구 프로그램·실험 데이터 전체 읽기 → 코드 작성·수정 → 오류 검증 → 결과 재확인」**을 수백 차례 반복하기 때문입니다. 한 번 코드를 수정하거나 검증할 때마다 AI가 앞선 방대한 연구 자료와 프로그램 전체를 처음부터 다시 읽어야 정확한 수정이 가능하므로, 10월 한 작업 환경 실측 기준으로만 약 **427.38억 토큰(데이터 처리 단위)**에 달하는 대규모 연산량이 필연적으로 발생합니다.

## 4. 구독 방식의 비용상 이점 및 경제성

관측된 데이터 처리량을 사용한 만큼 지불하는 종량제(API)로 환산하면 **10억 단위당 약 $488.71**이 소요되나, **월 $200 정액 구독을 활용할 경우 약 59.1%($288.71)의 비용 절감** 효과가 발생합니다 (월 4.09억 단위 초과 시 구독이 유리). 따라서 다량의 연구 분석을 처리하는 연구실 특성상 고정 구독 집행이 연구비 예산을 크게 절감하는 가장 합리적인 집행 방식입니다.

**근거 및 확인 범위:** 본 소명서는 과제 연구개발계획서, 연구 수행 기록 및 실제 데이터 처리량 집계에 근거하여 작성되었습니다. 비용 비교는 2026.11.04 공식 공개 단가를 적용한 조건부 계산(세금·별도 부가요금 제외)이며, 9건 개별 결제의 이용자·이용기간·담당 연구는 결제 영수증 및 연구실 증빙 자료와 대조하여 관리합니다.
