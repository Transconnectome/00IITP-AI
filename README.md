## 🏗️ Core Architecture: "The Two-Part Model"

이 과제의 핵심은 **"인간 기억 기전(Hippocampus)을 모사한 차세대 AI"**입니다.

1. **Sensory Encoder**: 시각(Vision)과 뇌파(LTC)를 처리하는 이중 경로.
2. **Titans Memory**: Surprise(예측 오차) 기반으로 중요한 정보만 장기 기억에 저장하는 SSM 모델.
